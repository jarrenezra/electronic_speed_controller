# electronic_speed_controller
This is University of West Florida's Fall 2026-Spring 2027 Senior Capstone Design. Our team consists of Ezra Manansala, Brendan Broyles, Parker Woodard, and Davi Farias. This team aims to design and build drone ESC for BLDCs using GaN FETs.
